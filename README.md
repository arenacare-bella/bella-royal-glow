# موقع Bella Royal Glow — إزاي تعدّل الموقع بنفسك

الموقع ده بيتحدث **لوحده** كل ما تحفظ تعديل هنا على GitHub. مش محتاج تعمل أي حاجة في Cloudflare.

## تغيير الأسعار أو الكلام أو العروض

1. افتح صفحة الريبو ده على الموبايل أو الكمبيوتر.
2. دوس على ملف اسمه **createLucideIcon-ZjcjU5d-.js**.
3. دوس على علامة القلم ✏️ (Edit) فوق على اليمين.
4. هتلاقي في أول الملف قدامك علامة واضحة مكتوب عليها **«عدّل من هنا»** وتحتها المحتوى:
   - `price:` السعر الحالي
   - `oldPrice:` السعر اللي بيتشطب (قبل الخصم)
   - `name:` اسم المنتج
   - `offers:` العروض (علبة واحدة / 1+1)
   - غيّر الأرقام أو الكلام اللي بين العلامتين ` ` بس، ومتلمسش باقي السطور.
5. انزل تحت ودوس الزرار الأخضر **Commit changes** وبعدين **Commit changes** تاني للتأكيد.
6. استنى دقيقة أو اتنين والموقع هيتحدث لوحده على نفس اللينك.

## تغيير صورة المنتج

1. افتح الريبو ودوس **Add file** ثم **Upload files**.
2. ارفع الصورة الجديدة بنفس الاسم ده بالظبط: **bella-model.jpg**
   - لو GitHub قالك الملف موجود، امسح القديم الأول (افتح الملف ودوس علامة سلة المهملات 🗑️ ثم Commit changes) وبعدين ارفع الجديدة.
3. استنى دقيقة أو اتنين.

## ملحوظة عن صفحة /admin

الموقع فيه صفحة إدارة (`/admin`) برقم سري. التعديلات اللي بتتعمل منها بتتسجل **على جهازك إنت بس** ومش بتظهر للزبائن. عشان التعديل يظهر لكل الناس، لازم يتعمل من GitHub زي ما هو مكتوب فوق.
